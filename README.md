# 汐汐小桌宠 🐾

基于《卡拉彼丘》汐汐表情包制作的**原生桌面宠物**。人物已从原图中单独抠出（透明背景 PNG），
用 PyQt5 无边框半透明窗口实现——真正的像素级透明直接看到桌面，拖动/缩放全走原生窗口消息，丝滑流畅。
带汐汐**真人语音**（中文配音陈婷婷 / 日文长谷川育美），中/日双语可切换，字幕始终中文。

## 玩法

- **🖐️ rua 头**：按住脑袋反复揉，每一下有挤压回弹 + 短促"敲脑袋"音；摸久了会开口说话
- **🍰 投喂**：食物从天而降掉进嘴里，咀嚼动画 + 饱食度回升，会说"大好人，谢谢你"
- **💬 聊聊**：关键词聊天；说"喜欢"回"你是我的偶像"；**带"对吗"的句子会随机回"对的对的 / 不对不对"**
- **🎙️ 语音随机混入**：说话、投喂、摸头、闲聊、打瞌睡等时刻，**一半概率出真人语音、一半概率出文字台词**（不会只出一种）；只有**开场自我介绍固定出语音**
- **🔀 语言切换**：底部栏「中/日」按钮一键切换配音语言，字幕始终中文
- **🖱️ 右键菜单**：在汐汐身上点右键，可以选择语音、休息或退出；唤回按钮的右键菜单也能退出
- **🖱️ 拖动 / 🔍 滚轮缩放**：按住身体拖动，人物支持 50%～200% 缩放；窗口会保留完整按钮栏所需的宽度，缩放后调整位置以留在屏幕内
- **😴 睡觉 / 💤 半虚化**：约 75～80 秒没有操作后入睡，自动闲聊不会推迟入睡；摸头、拖动、打字和点按钮会重新计时；鼠标移开时按钮状态栏淡出
- **✕ / 🔊**：右侧小叉让她休息，之后点击独立的「唤回汐汐」按钮叫她回来；休息期间暂停闲聊、状态衰减和渲染；喇叭切换声音

选中桌宠或唤回按钮后，按 `Alt+F4` 可以退出程序。
位置、缩放、配音语言和声音开关会自动保存在项目目录的 `pet_settings.json`，退出后再次启动会恢复。
断开副屏或修改分辨率时，窗口会移回可用屏幕；当前屏幕放不下时，会下调缩放比例。

## 启动方式

双击 **`启动桌宠.bat`**。首次启动时，汐汐会出现在屏幕右下角（无边框、透明、置顶），之后恢复上次保存的位置与设置。

需要 Python 3.8 或以上版本。启动器优先使用项目目录内 `.venv`、`venv` 中的 Python，
然后查找系统的 `py -3` 和 `python`。缺少依赖时会显示 PowerShell 安装命令，按提示安装后重新启动。

在项目目录中手动安装运行依赖：

```powershell
python -m pip install -r requirements.txt
```

使用 `py -3` 或虚拟环境时，可以直接复制启动器提示的 PowerShell 安装命令，确保依赖装入同一个环境。
启动器只提示安装命令，下载安装由用户手动执行。

资源路径以脚本所在的项目目录为准。换机器时保留完整目录（含 `voice/`）；
`python make_share.py` 生成的分享包也会包含同一份启动器和运行依赖清单。
分享包不包含本机的 `pet_settings.json`，对方会从默认设置开始使用。

运行抠图脚本前，先执行 `python -m pip install -r requirements-tools.txt`，
再把原图 `source.jpeg` 和 u2net 输出的蒙版 `xixi_raw.png` 放在项目目录。
脚本会将结果保存为项目内的 `xixi.png`。

## 语音说明

- 语音来自《卡拉彼丘》官方 WIKI（wiki.biligame.com/klbq），仅供个人学习娱乐使用，版权归游戏方所有
- 台词精选自「获得角色 / 确认准备 / 回合开场 / 战斗胜利 / 战斗失败 / 飘飞 / 快捷沟通」等场景
- 中文配音：陈婷婷；日文配音：长谷川育美
- 语音最多同时播放两段。新语音开始时，上一段会在 300 毫秒内淡出；连续触发第三段时，停止最早的一段
- 语音使用两个专用声道，摸头、投喂等音效使用其余声道。点击静音会停止当前所有声音

## 自定义

- **换台词**：打开 `pet_qt.py`，找 `LINES`（文字台词）和 `VOICE_TEXTS`（语音字幕）两个字典
- **调语音出现概率**：搜 `_say_or_voice` 方法里的 `voice_prob=0.5`
- **换人物**：把新的透明背景 PNG 命名为 `xixi.png` 替换，删掉 `xixi_sad.png` 重新生成
- **调大小**：搜 `BASE_W, BASE_H = 400, 480`（窗口）和 `PET_BASE_W = 204`（人物）
- **调虚化程度**：搜 `IDLE_UI_OPACITY = 0.55`
- **回退第一版**：把 `启动桌宠.bat` 里的 `pet_qt.py` 改成 `pet_qt_v1.py`
